## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `README.md` y la carpeta `images/` con las fotos.
3. Ve a Settings > Pages, elige la rama `main` y la carpeta `/ (root)`, y guarda.
4. En unos minutos la página estará disponible en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
